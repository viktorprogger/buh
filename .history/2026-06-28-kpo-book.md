# KPO Book for Paušal Entrepreneurs

**Date:** 2026-06-28
**Branch:** feature/kpo-book

## Problem

Accountants need to maintain a KPO ("Knjiga prihoda i ostalih prihoda") ledger for each paušal entrepreneur, per year. The entrepreneur page should open the current year by default and allow managing entries for any year.

## Approach

- Two new DB tables: `kpo_books` (one per entrepreneur+year) and `kpo_entries`
- New `internal/kpo` package with repo methods
- `GET /entrepreneurs/{id}?year=YYYY` auto-creates the KPO book for the requested year and renders it
- POST routes under `/entrepreneurs/{id}/kpo/{year}/...` for entries + finalization
- Entrepreneur template updated: year tabs, keyboard-first entry row (HTML5 `form` attribute pattern to embed inputs in a table row), inline total computation via JS
- Finalization: marks the book as locked (read-only), can be reversed with "Откључај"

## Key decisions

- KPO fields chosen by user: redni broj (auto), datum naplate, broj računa, iznos od prodaje proizvoda, iznos od usluga, укупно
- `form` attribute on inputs to keep valid HTML while having a form that spans a table row
- `not` used in template (Go built-in template function)
- `FinalizedAtStr()` helper method to avoid dereferencing `*time.Time` in template

## Tests

Playwright tests cover: auto-create current year, add entry via keyboard, delete entry, finalize, unfinalize, add previous year, year tabs navigation.
